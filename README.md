Hola, este es el manual de uso del programa de la Tienda de Emilio 

Funcionamiento del programa: 

1) Selecciona la opción escribiendo el numero correspondiente a esa elección. 
    Ejemplo: 

    --BIENVENIDO A LA TIENDA DE EMILIO--
Seleccione una opción:

1. Registra venta de producto
2. Salir del sistema
3. Ver ventas anteriores

Opción: "1" 

2) Escoge el codigo del producto que deseas seleccionar como lo indica el menú.

3) Escoge la marca del producto que deseas selccionar. 

4) Ingrese la cantidad de productos que el cliente pidió.

5) Seleccione el número que sea escoger para la siguente acción.

6) Si agrega un nuevo producto, repita al partir del paso 2.

7) Si imprime el ticket.

8) Si desea ver las ventas anteriores, por favor seleccione la opción tres (tras haber finalizado una venta).
