Hola, este es el manual de uso del programa de la Tienda de Emilio 

Funcionamiento del programa: 

1) Selecciona la opción escribiendo el numero correspondiente a esa elección. 
    Ejemplo: 

    --Bienvenido a tienda de Emilio--
Seleccione una opción:

1. Registra venta de producto
2. Salir del sistema

Opción: "1" 

2) Escoge el codigo del producto que deseas seleccionar como lo indica el menu 

3) Escoge la marca del producto que deseas selccionar como lo indica el menu 

4) Ingrese la cantidad de productos que el cliente le pidió

5) Seleccione el numero que sea escoger para la siguente acción

6) Si agrega un nuevo producto, repita desde el paso 2 

7) Si imprime el ticket
